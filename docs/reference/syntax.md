# Синтаксис

Формальная грамматика (EBNF) — в [legacy §3](spec-legacy.md).
Здесь — правила оформления и ограничения, нарушение которых чаще всего
приводит к ошибкам. Термины — по [глоссарию](../glossary.md).

## Файл

```text
{ use "path"; } { const|fun|pred|time_const } schedule "..." { ... }
```

Порядок членов расписания `schedule`: точки `point*`, затем рутины
`routine*`, затем циклы `cycle*`, затем корневой цикл `root_cycle`
(ровно один).

## Имена

- `IDENT`: буквы ASCII, цифры и `_`; начинается с буквы или `_`;
  регистр значим. Не-ASCII в именах запрещены.
- Точки, рутины и циклы находятся в общем пространстве имён:
  столкновение — ошибка `E09`. Таблицы времени — в собственном пространстве.
  Действия принадлежат пространству своей точки: одно имя в разных точках
  допустимо.

## Длительности и смещения

Компоненты длительности `duration` упорядочены строго по убыванию
`w > d > h > m > s > ms`, каждый встречается не более раза
(`1h20m` — корректно, `1h2h` — ошибка `E05`). `ms` токенизируется как единый
юнит. Порядок и уникальность компонентов проверяются валидацией.

Отрицательное смещение пишется слитно (`-10m: …`) и разрешено только у строки.
Оно означает `duration` объемлющего цикла минус указанная величина.
Смещение `-0m` эквивалентно концу цикла. Отрицательные длительности
в заголовках запрещены.

## Строки и повторы

```text
[условие] смещение: [repeat N | fill [until T]] вызов;
```

Повторы `repeat`/`fill` допустимы только для вызовов циклов; повтор вызова
точки — ошибка `E10`. Запись `repeat 0` запрещена. Горизонт `until T`
отсчитывается от старта объемлющего цикла, а не от позиции строки.

## Условия

Условие — выражение `[…]` перед смещением строки. Одиночный вызов предиката
(`[weekend(at)]`) допустим; в остальных позициях требуется сравнение.
Приоритет операций: скобки → унарный минус → `*/%` → `+-` → `++` →
`<<>>` → `&` → `^` → `|` → сравнение → `not` → `and` → `or`.

Условие, зависящее только от времени суток без даты, постоянно во всех
экземплярах; ветви будних дней записываются в паре с календарным предикатом
(`weekend`, `workday`).

## Данные

Мапы, массивы и `true`/`false` — только литералы в объявлениях `const`,
аргументах вызовов, атрибутах действия и атрибутах `attrs`. Доступ к полям —
через точку (`subj.name`), к элементам — по литеральному индексу (`tags[0]`).
Повторные ключи мапы — ошибка `E15`.
