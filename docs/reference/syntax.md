# Синтаксис

EBNF-грамматика — в `crates/cyclorithm-core/src/parser/grammar.pest`.
Здесь — правила словами и на примерах: что можно писать и где границы.
Что означают сущности — в [концептах](concepts.md).

## Файл

Файл — это шапка импортов, объявления и одно расписание:

```cyclo
use "libs/route_lib.cyclo";

const MORNING = 6;

schedule "Автобусный парк" {
  ...
}
```

Порядок членов расписания строгий: опциональная `timezone`, затем точки,
затем рутины, затем циклы, затем корневой цикл (ровно один):

```cyclo
schedule "Автобусный парк" {
  timezone = "+03:00"  // или "Z" — опционально, первой строкой, без запятой
  point DEPOT { ... }  // затем точки
  routine MONDAY(TC) { ... }  // затем рутины
  cycle CITY_ROUTE duration = 1h20m { ... }  // затем циклы
  root_cycle start_time = "...", duration = 24h { ... }  // корневой — последний
}
```

Поля шапки корневого цикла — в любом порядке через запятую
(`duration = 24h, start_time = "..."` — то же самое); висячая запятая
перед `{` запрещена, как везде в языке. Нет обязательного поля —
ошибка `missing-argument`, поле дважды — `duplicate-argument`.

`timezone` — только `Z` или числовой `±HH:MM`. Имена зон (`MSK`,
`Europe/...`) — ошибка `invalid-timezone`: пишите числовой офсет.
Имена IANA с переходами DST — в [todo](../todo.md).

Комментарии `//` до конца строки лексер выбрасывает как пробелы — разрешены
между любыми токенами. Внутри строк `"..."` двойной слеш — обычный текст.

## Имена

Имена — буквы ASCII, цифры и `_`, начинаются с буквы или `_`. Регистр значим
(`DEPOT` и `Depot` — разные имена), кириллица запрещена.

Одно имя `depart` в разных точках — можно: действия живут в пространстве
своей точки. Одно имя у точки и цикла — нельзя, пространства общие.
Слова `repeat`, `fill`, `gaps`, `until` в строках распознаются по месту —
циклам и действиям такие имена не давать:

```cyclo
point DEPOT { actions = [depart]; }
point AIRPORT { actions = [depart]; }  // можно: разные точки

point X { ... }
cycle X duration = 1h { ... }  // ошибка wrong-kind: имя занято
```

## Длительности и смещения

Что такое длительность и смещение — в [концептах](concepts.md).
Здесь только формальные ограничения: компоненты строго по убыванию
`w > d > h > m > s > ms`, каждый встречается не более раза (`1h2h` —
ошибка `invalid-duration`). `ms` — единый юнит, а не `m` + `s`. Значение обязано влезать
в `i64` миллисекунд.

## Строки и повторы

Строка — условие, смещение, необязательный повтор и вызов:

```cyclo
[not weekend(at)] 10h: repeat 2 SHUTTLE();  // условие + смещение + повтор + вызов
14h: fill until 15h SHUTTLE();
0h: fill gaps BREAK_20();  // добивка пустот, без until — до конца цикла
0h: fill gaps until 2h30m BREAK_5();
6h: CITY_ROUTE();
```

Повторы — только для циклов: повтор действия точки — ошибка `repeat-point-action`,
`repeat 0` запрещён. Горизонт `until` считается от старта объемлющего цикла,
а не от строки.

## Разворот циклов

Производный цикл — зеркало имеющегося:

```cyclo
cycle KULICHKI_TAMBOV reverse TAMBOV_KULICHKI;
```

Параметры и длительность наследуются, тела нет. Что зеркалится и как
проверяется — в [семантике](semantics.md). Живой пример — `examples/real/101.cyclo`.

Блок атрибутов действия — JSON-словарь после вызова точки:
`{"ключ": значение, …}`. Ключи — строки, значения — выражения уровня условий
(динамика `subj.…` работает). Вместо литерала можно сослаться на
константу-мапу: `BELL.ring() CORPUS;` (константа статична, параметры цикла
внутри недоступны). Пустой `{}` разрешён; дубли ключей — `duplicate-attribute`.

## Условия

Условие — выражение `[…]` перед смещением строки. Простейшее — одиночный
вызов предиката, остальное — сравнения с логикой. Как в C, годится и голое
число: ноль — ложь, ненулевое — истина:

```cyclo
[weekend(at)] 12h: CITY_ROUTE();  // голый предикат
[hour(at) >= 7 and not weekend(at)] 10h: SHUTTLE();  // сравнение и логика
[5] 6h: CITY_ROUTE();  // всегда истина
[hour(at) - 6] 6h: SHUTTLE();  // истина, пока не 6:00
```

Строки, словари и массивы в позиции условия запрещены (`type-mismatch`):
голое значение почти всегда означает забытое сравнение. Имена данных
напрямую — тоже (`unknown-name`). Голый `at` — миллисекунды момента строки,
то есть практически всегда истина.

Приоритет операций, от крепкого к слабому:

- скобки `(…)`
- унарный минус
- `*` `/` `%` `floordiv` `floormod`
- `+` `-`
- `++` (строки)
- `<<` `>>`
- `&`
- `^`
- `|`
- сравнения
- `not`
- `and`
- `or`

Время суток без даты постоянно во всех экземплярах: будние ветви пишутся
в паре с календарным предикатом (`weekend`, `workday` — из [стандартной
библиотеки](stdlib.md), подключать не нужно).

## Данные

Данные — целые и дробные числа, строки, `true`/`false`, словари и массивы.
Дробные литералы — с точкой и/или экспонентой (`20.02`, `.02`, `1e6`,
`1.2e-3`); `20.` с хвостовой точкой допустима, но `20.foo` — это число `20`
и поле `foo`, а не дробь. В длительностях (`1h20m`) дроби запрещены.
Значения словарей и массивов — выражения: имена (константы и параметры),
`at`, арифметика, склейка, вызовы. Они вычисляются в момент использования
с той же динамической областью видимости, что и везде: параметр цикла
перекрывает `const` с тем же именем.

```cyclo
const ROOM = "233/А";
const LEC = {"subject": "БЖД", "room": ROOM, "label": ROOM ++ ", корпус Л"};
const GEO = {"lat": 20.02, "lon": 23.43};
```

Словари — в JSON-стиле, как в примере выше. Литерал годен и прямо
в аргументе: `LESSON({"subject": subject})`.

Строки `"..."` — однострочные, экранирования нет: кавычку внутрь строки
никак не вставить.

Запятые — только между элементами: висячая запятая после последнего
запрещена везде — в списках, словарях и блоках.

Доступ к полям — через точку, к элементам — по индексу-выражению.
Неотрицательный индекс считается с начала, отрицательный — с конца
(`tags[-1]` — последний элемент). Индекс — обычное числовое выражение
(имена, арифметика, `at`), пробелы внутри допустимы; вне границ —
`index-out-of-bounds`:

```cyclo
subj.subject  // поле словаря
tags[0]  // первый элемент массива
tags[-1]  // последний элемент
tags[i + 1]  // индекс-выражение
```

Вычисляемых **ключей** словаря нет (доступ к полям только через `.поле`),
повторные ключи словаря — ошибка `duplicate-attribute`.
