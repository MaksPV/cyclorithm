# Синтаксис

EBNF-грамматика — в `crates/cyclorithm-core/src/parser/grammar.pest`.
Здесь — правила словами и на примерах: что можно писать и где границы.
Значения терминов приведены в разделе [«Основные понятия»](concepts.md).

## Файл

Файл содержит импорты, объявления и одно расписание. Директивы `use`
могут стоять между объявлениями. Файл заканчивается блоком расписания:

```cyclo
use "libs/route_lib.cyclo";

const MORNING = 6;
use "libs/holidays.cyclo";  // можно и здесь — всё равно до расписания

schedule "Автобусный парк" {
  ...
}
```

Точки, рутины, циклы и корневой цикл можно объявлять в любом порядке.
В расписании должен быть ровно один корневой цикл. Поле `timezone`
необязательно. Его можно указать один раз, без запятой:

```cyclo
schedule "Автобусный парк" {
  root_cycle start_time = "...", duration = 24h { ... }  // хоть первым
  point DEPOT { ... }
  timezone = "+03:00"  // или "Z"
  routine MONDAY(TC) { ... }
  cycle CITY_ROUTE duration = 1h20m { ... }
}
```

Поля заголовков — в любом порядке (разделитель тот же: запятая у `root_cycle`,
точка с запятой у `point`, пробел у `cycle`); завершающие разделители запрещены,
как везде в языке. Нет обязательного поля — ошибка `missing-argument`,
поле дважды — `duplicate-argument`:

```cyclo
root_cycle duration = 24h, start_time = "..." { ... }  // то же самое
point DEPOT { attrs = {...}; actions = [depart]; }  // то же самое
cycle CITY_ROUTE duration = 1h20m { ... }  // параметры (если есть) — тоже в любом порядке
```

У `time_const` и `routine` поле одно (`duration` / параметры), переставлять
нечего; отсутствие табличного параметра рутины — `no-table-parameter`.

`timezone` — только `Z` или смещение `±HH:MM`. Имена зон (`MSK`,
`Europe/...`) — ошибка `invalid-timezone`: укажите числовое смещение.
Поддержка часовых поясов IANA описана в [планах](../todo.md#iana-and-dst).

Комментарий начинается с `//` и продолжается до конца строки. Между элементами языка он служит пробелом. В строковом литерале `//` остаётся частью текста.

## Имена

Имена — буквы ASCII, цифры и `_`, начинаются с буквы или `_`. Регистр значим
(`DEPOT` и `Depot` — разные имена), кириллица запрещена.

У разных точек может быть действие с одним и тем же именем. Имена
самих точек и циклов должны быть уникальны в расписании. Избегайте слов
`repeat`, `fill`, `gaps` и `until` в именах циклов и действий: в строках
они используются как ключевые слова.

```cyclo
point DEPOT { actions = [depart]; }
point AIRPORT { actions = [depart]; }  // можно: разные точки

point X { ... }
cycle X duration = 1h { ... }  // ошибка wrong-kind: имя занято
```

## Длительности и смещения

Длительность и смещение описаны в разделе [«Основные понятия»](concepts.md).
Здесь только формальные ограничения: компоненты строго по убыванию
`w > d > h > m > s > ms`, каждый встречается не более одного раза (`1h2h` —
ошибка `invalid-duration`). `ms` обозначает миллисекунды. Длительность в миллисекундах должна помещаться в `i64`.

## Строки и повторы

У строки обязательно есть момент и вызов. Условие, повтор и метка запуска необязательны:

```cyclo
[not weekend(at)] 10h: repeat 2 SHUTTLE();  // условие + момент + повтор + вызов
14h: fill until 15h SHUTTLE();
0h: fill gaps BREAK_20();  // добивка пустот, без until — до конца цикла
0h: fill gaps pack right BREAK_20();  // встык справа
0h: fill gaps pack center until 2h30m BREAK_5();  // по центру отрезка
0h: fill gaps until 2h30m BREAK_5();
6h: CITY_ROUTE();
0h: WARMUP() as W1;  // метка запуска для ссылок after/at/until
after W1: PRODUCTION();  // зависимость от конца W1
+10m: COFFEE();  // через 10 минут после курсора
+: SHOWER();  // сразу после курсора
max(8h, end(W1)): INSPECTION();  // функция момента
```

У каждой строки один источник момента: смещение от начала или конца цикла
(`0h:`, `8h30m:`, `-0m:`), смещение от курсора (`+:`, `+10m:`),
зависимость (`after W1:`, `at W1:`, `until W1:`) или функция
(`start(W1)`, `end(W1)`, `max(...)`, `min(...)`). Запись
`0h: FOO() after W1;` содержит два источника и вызывает синтаксическую
ошибку. Ссылаться можно на метки, объявленные выше в теле того же цикла.
Метка `as` ставится у вызова цикла.

В рутинах допустимы только смещения и метки слотов таблицы (`1st:`).
Другие выражения момента вызывают `invalid-routine-moment`.
Для строки `fill gaps` и тела исходного цикла в объявлении `reverse`
допустимы только абсолютные смещения. Строки с динамическими моментами
должны стоять перед первой строкой `fill gaps` в том же цикле.

Повторы применяются к циклам. Попытка повторить действие точки приводит к
`repeat-point-action`. Число в `repeat` должно быть больше нуля. Граница
`until` отсчитывается от начала текущего цикла.

## Разворот циклов

Производный цикл — зеркало имеющегося:

```cyclo
cycle KULICHKI_TAMBOV reverse TAMBOV_KULICHKI;
```

Параметры и длительность берутся из исходного цикла. Тело строится
по [правилам разворота](semantics.md#reverse-cycles). Пример расписания
с обратным маршрутом — `examples/real/101.cyclo`.

## Атрибуты действия

Блок атрибутов действия — JSON-словарь после вызова точки:
`{"ключ": значение, …}`. Ключи записываются строками, значения могут быть
выражениями с параметрами текущего цикла. Можно также указать имя
константы со словарём, например `BELL.ring() CORPUS;`. К параметрам цикла
внутри константы обращаться нельзя. Пустой словарь `{}` допустим.
Повторяющиеся ключи приводят к ошибке `duplicate-attribute`.

## Условия

Условие — выражение `[…]` перед смещением строки. Простейшее — одиночный
вызов предиката, остальное — сравнения с логикой. Как в C, годится и голое
число: ноль — ложь, ненулевое — истина:

```cyclo
[weekend(at)] 12h: CITY_ROUTE();  // голый предикат
[hour(at) >= 7 and not weekend(at)] 10h: SHUTTLE();  // сравнение и логика
[5] 6h: CITY_ROUTE();  // всегда истина
[hour(at) - 6] 6h: SHUTTLE();  // истина, пока не 6:00
```

Строка, словарь или массив в роли условия приводят к `type-mismatch`.
Чтобы использовать эти данные, составьте сравнение или обратитесь к нужному
полю. Имя константы со словарём, строкой или массивом в условии вызывает
`unknown-name`. Для сравнения момента строки с числом используйте
`at.wall` или `at.abs`.
В условиях можно обращаться к полям словаря [`here`](semantics.md#here), например `len(here.enabled_events) > 0`.

Приоритет операций, от высшего к низшему:

- скобки `(…)`
- унарный минус
- `*` `/` `%` `floordiv` `floormod`
- `+` `-`
- `++` (строки)
- `<<` `>>`
- `&`
- `^`
- `|`
- сравнения
- `not`
- `and`
- `or`

Для расписания по дням недели используйте календарные предикаты,
например `weekend` или `workday`. Они доступны из [стандартной библиотеки](stdlib.md)
без импорта.

## Данные {#data}

Данные — целые и дробные числа, строки, `true`/`false`, словари и массивы.
Дробные литералы — с точкой и/или экспонентой (`20.02`, `.02`, `1e6`,
`1.2e-3`); `20.` с хвостовой точкой допустима, но `20.foo` — это число `20`
и поле `foo`, а не дробь. В длительностях (`1h20m`) дроби запрещены.
Значения словарей и массивов — выражения: имена (константы и параметры),
`at`, арифметика, склейка, вызовы. Они вычисляются в момент использования
с той же динамической областью видимости, что и везде: параметр цикла
перекрывает `const` с тем же именем.

```cyclo
const ROOM = "233/А";
const LEC = {"subject": "БЖД", "room": ROOM, "label": ROOM ++ ", корпус Л"};
const GEO = {"lat": 20.02, "lon": 23.43};
```

Словари — в JSON-стиле, как в примере выше. Словарь можно передать напрямую: `LESSON({"subject": subject})`.

Строки `"..."` — однострочные, экранирования нет: кавычку внутрь строки
никак не вставить.

Запятые — только между элементами: висячая запятая после последнего
запрещена везде — в списках, словарях и блоках.

Доступ к полям — через точку, к элементам — по индексу-выражению.
Неотрицательный индекс считается с начала, отрицательный — с конца
(`tags[-1]` — последний элемент). Индекс — обычное числовое выражение
(имена, арифметика, `at`), пробелы внутри допустимы; вне границ —
`index-out-of-bounds`:

```cyclo
subj.subject  // поле словаря
tags[0]  // первый элемент массива
tags[-1]  // последний элемент
tags[i + 1]  // индекс-выражение
```

Вычисляемых **ключей** словаря нет (доступ к полям только через `.поле`),
повторные ключи словаря — ошибка `duplicate-attribute`.
