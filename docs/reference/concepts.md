# Концепты

Что означает каждая сущность расписания и как она записывается.
Термины — в [глоссарии](../glossary.md), полные определения —
в [legacy-спеке](spec-legacy.md).

## Расписание `schedule`

Корень файла. Связывает точки, шаблоны и корневой цикл в одно целое.

- Запись: `schedule "Имя" { … }`.
- Имя попадает в поле `schedule` вывода.

```text
schedule "Автобусный парк" {
  point DEPOT {
    actions = [depart, arrive];
  }
  root_cycle start_time = "2026-01-09T00:00:00", duration = 24h {
    6h: DEPOT.depart();
  }
}
```

## Точка `point`

Место, где происходят действия: парк, аэропорт, звонок.

- Член расписания.
- Объявляет допустимые действия `actions`.
- Необязательные атрибуты `attrs` — словарь, копируемый в каждое событие.

```text
point DEPOT {
  actions = [depart, arrive];
}
```

## Действие `action`

То, что происходит в точке. Попадает в вывод полем `action`.

- Вызывается как `<ТОЧКА>.<действие>()`.
- Может нести атрибуты действия `{k = v, …}`.

```text
0m: DEPOT.depart();
40m: AIRPORT.arrive();
```

## Цикл `cycle`

Именованная цепочка строк. Вызывается из корневого цикла или из другого
цикла. Сам по себе событий не порождает.

- Член расписания.
- Заголовок: необязательные параметры и длительность `duration`.
- Тело: строки `<смещение>: <вызов>;`.

```text
cycle CITY_ROUTE duration = 1h20m {
  0m: DEPOT.depart();
  40m: AIRPORT.arrive();
}
```

## Корневой цикл `root_cycle`

Задаёт решётку стартов — когда запускаются циклы и одиночные действия.

- Ровно один в расписании.
- Пара `start_time` + `duration`, где `duration` — период решётки.
- Окно CLI `--start/--end` пересекают с этой решёткой.

```text
root_cycle start_time = "2026-01-09T00:00:00", duration = 24h {
  6h: CITY_ROUTE();
}
```

## Вызов `invocation`

Единица выполнения внутри строки.

- Действие точки даёт событие: `ТОЧКА.действие() [{…}]`.
- Вызов цикла или рутины раскрывается в строки: `ИМЯ(аргументы)`.

```text
0m: DEPOT.depart() { fuel_used = 25 };
6h: CITY_ROUTE();
0h: MONDAY(DAY);
```

## Событие `event`

Единица вывода — то, что произошло в конкретный момент.

- Форма: `{time, action, point, point_attrs, action_attrs}`.
- Источник: строка с действием точки внутри вызванного цикла.

```json
{"time": "2026-01-09T06:00:00", "action": "depart", "point": "DEPOT", "point_attrs": {}, "action_attrs": {}}
```

## Таблица времени `time_const`

Именованные метки времени в одном месте. Смена таблицы сдвигает все дни
сразу: сокращённый день — та же рутина, другая таблица.

- Объявление верхнего уровня, как `const`/`fun`/`pred`.
- Импортируется через `use`.
- Каждая строка обязана иметь метку.

```text
time_const DAY duration = 21h35m {
  1st: 9h;
  2nd: 10h45m;
}
```

Строка таблицы может нести вызов со стрелкой `->` — фиксированное событие
дня, объявленное один раз на таблицу, а не на каждый день. Такая строка
выполняется при каждом применении таблицы, может иметь собственное условие:

```text
time_const DAY duration = 21h35m {
  [workday(at)] lunch: 12h20m -> LUNCH();
}
```

## Рутина `routine`

Шаблон дня. Тело записано метками вместо смещений, поэтому едет на разных
сетках звонков без переписывания.

- Член расписания между точками и циклами.
- Первый параметр — всегда таблица времени, остальные — данные, как у цикла.
- Вызов `ИМЯ(ТАБЛИЦА, …)` заменяет метки смещениями таблицы.
- Вызовы таблицы добавляются после строк тела.

```text
routine MONDAY(TC) {
  1st: LESSON(BJD_LECTURE);
}
```

## Условие и момент строки `at`

Условие гасит строки, не подходящие под календарь: будни, праздники, часы.

- Запись `[выражение]` перед смещением строки.
- Вычисляется для момента строки `at` — абсолютного времени строки.
- Момент строки: старт объемлющего цикла плюс смещение.

```text
[not weekend(at)] 6h: CITY_ROUTE();
```

## Повтор (`repeat` / `fill`)

Цепочка экземпляров цикла вместо одного: фиксированная или
«сколько поместится».

- Модификатор строки между `:` и вызовом.
- `repeat N` — строгий режим: ровно `N` экземпляров.
- `fill [until T]` — мягкий режим: пока помещается в объемлющий цикл.
- Горизонт `until T` отсчитывается от старта родителя.

```text
10h: repeat 2 SHUTTLE();
14h: fill until 15h SHUTTLE();
```

## Как связаны

```text
расписание schedule
├── точка point → действия actions (+ атрибуты attrs → point_attrs)
├── таблица времени time_const → метки + строки со стрелкой ->
├── рутина routine(ТАБЛИЦА) → тело на метках
├── цикл cycle → строки <смещение>: вызов
└── корневой цикл root_cycle → решётка start_time/duration → вызовы → события
```
