# Выражения

Чем считаются условия, блоки и аргументы: значения, арифметика, строки,
даты, битовые операции. Приоритет операций — в [синтаксисе](syntax.md).

## Значения

Шесть видов: целые числа (`i64`; `at` — миллисекунды от epoch), дробные
числа (`f64`: `20.02`, `.02`, `20.`, `1e6`, `1.2e-3`), строки,
`true`/`false` (с границей слова: `truex` — имя, не литерал), словари
и массивы. Отдельного типа «булево» нет, но любое число годится в условие
напрямую (C-стиль: `0` и `0.0` — ложь, ненулевое — истина).

## Арифметика

Операции `+`, `-`, `*`, `/`, `%`, `floordiv`, `floormod`, унарный минус.
Деление `/` усекает к нулю, остаток `%` наследует знак делимого;
`floordiv`/`floormod` округляют к минус бесконечности.

Деление и остаток на ноль — ошибка `division-by-zero`: константный ноль
ловится сразу, ноль выражением — в момент строки.

```text
division by zero
```

Переполнение любой операции — ошибка `integer-out-of-range` (целые) или
`float-out-of-range` (дробные), тоже в момент строки. Смешанная арифметика
`+ - * /` повышает целое до дробного (`1 + 20.02 == 21.02`); `%`,
`floordiv`, `floormod` — только для целых (`type-mismatch` на дробных).

## Сравнения

Число сравнивается с числом (целое с дробным — через повышение до `f64`),
строка со строкой (побайтово), все шесть операторов. Цепочки запрещены
(`a < b < c` — синтаксическая ошибка).
Словари и массивы не сравниваются (`maps-not-comparable`).

## Строки

Конкатенация `++` — только для строк. Функции `str(n)` (десятичная запись,
принимает и дробные: `str(20.02) == "20.02"`) и `pad(n, w)` (добивка нулями
слева до ширины `w`, только целые; ширина больше 1024 — `string-too-long`).

Список дат — строковой альтернацией, только со строкой слева и только
`==`/`!=`. Ветки — числовые выражения, `and` внутри веток — синтаксическая
ошибка:

```cyclo
pred holiday(at) = datestr(at) == ("2026-11-04" or "2026-12-31");
```

## Даты

Литералы дат — `YYYY-MM-DDTHH:MM:SS[.mmm][Z|±HH:MM]`; без суффикса — наивное
(1:1 как написано), с `Z`/±HH:MM` — aware (инстант `wall − offset`). Аббревиатуры
типа `MSK` не поддерживаются — пишите числовой офсет `+03:00`. Сравнение дат
идёт по абсолютным миллисекундам: наивное `06:00` ≡ `06:00Z`, но `06:00` ≠ `06:00+03:00`.

Конструктор `mkdate(y, mo, d, h, mi, s, ms)` собирает наивное время:
месяц `1..12`, день в пределах месяца, часы `0..23`, минуты и секунды
`0..59`, миллисекунды `0..999`. Кривые компоненты — ошибка `invalid-date`:

```text
invalid date '2026-13-40T0:0:0.0'
```

Голый `at` рядом со строкой приводится к канонической форме `datetimestr(at)`
(`YYYY-MM-DDTHH:MM:SS.mmm`).

## Битовые

Операции `<<`, `>>`, `&`, `|`, `^` — только над целыми числами (дробные —
`type-mismatch`), переполниться не могут: лишние биты роняются (wrap).
Сдвиг вправо `>>` — логический (добивка нулями), величина сдвига берётся
по модулю 64:

```cyclo
[(1 << 70) == 64] 2h: DEPOT.depart();  // 70 → 6, 2^6 = 64 — событие в 2:00
```

## Мостик `truth`

Скобки с условием работают в обе стороны. В позиции условия скобка без
продолжения — группировка: `[(hour(at) >= 0)]` то же, что `[hour(at) >= 0]`.
А условие в скобках как операнд — значение `1` или `0`:

```cyclo
[(hour(at) >= 0) == 1] 7h: DEPOT.depart();  // истина → 1 — событие есть
[1 * (hour(at) >= 7) == 1] 7h: DEPOT.depart();  // в 7:00 истина → 1 — событие есть
```

Скобки с чистой арифметикой — обычный операнд: `[(hour(at) + 1) == 8]`.

## Две проверки

Статика ловит до разворачивания: смешение типов, неверную арность,
константный ноль, кривой константный `mkdate`, невлезающий литерал числа
(`integer-out-of-range`, `float-out-of-range`), рекурсию объявлений.
Остальное — в момент строки: ноль выражением, кривой `mkdate` выражением,
переполнение, ошибки доступа к данным (`unknown-field`,
`index-out-of-bounds`). Индекс массива — только целое (`type-mismatch`
на дробном).
