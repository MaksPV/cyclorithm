# Выражения

Выражения используются в условиях, аргументах и атрибутах. Порядок
вычисления операторов описан в [справочнике синтаксиса](syntax.md).

## Значения

Шесть видов: целые числа (`i64`), дробные
числа (`f64`: `20.02`, `.02`, `20.`, `1e6`, `1.2e-3`), строки,
`true`/`false` (с границей слова: `truex` — имя, не литерал), словари
и массивы. Отдельного типа «булево» нет, но любое число годится в условие
напрямую (C-стиль: `0` и `0.0` — ложь, ненулевое — истина).

Момент строки `at` — словарь `{wall, abs, zone}` (см. [семантику](semantics.md)):
местное время, абсолютное время и смещение от UTC в миллисекундах.
Для числовых операций используйте поля `at.wall` или `at.abs`.
Функция `len(x)` возвращает число символов строки, элементов массива
или ключей словаря. `keys(m)` и `values(m)` возвращают ключи или
значения в порядке объявления. Неподходящий тип аргумента вызывает
`type-mismatch`.

## Арифметика

Операции `+`, `-`, `*`, `/`, `%`, `floordiv`, `floormod`, унарный минус.
При делении целых чисел `/` округляет результат к нулю. Остаток `%`
имеет знак делимого, если он ненулевой. `floordiv` округляет частное
вниз, а `floormod` даёт соответствующий остаток. Например, `7 floordiv -3`
равно `-3`, а `7 floormod -3` равно `-2`.

Деление на ноль и вычисление остатка с нулевым делителем дают
`division-by-zero`. Литеральный ноль обнаруживается при проверке,
ноль в результате выражения — при расчёте строки.

```text
division by zero
```

Переполнение любой операции — ошибка `integer-out-of-range` (целые) или
`float-out-of-range` (дробные), тоже в момент строки. Смешанная арифметика
`+ - * /` повышает целое до дробного (`1 + 20.02 == 21.02`); `%`,
`floordiv`, `floormod` — только для целых (`type-mismatch` на дробных).

## Сравнения

Число сравнивается с числом (целое с дробным — через повышение до `f64`),
строка со строкой (побайтово), все шесть операторов. Цепочки запрещены
(`a < b < c` — синтаксическая ошибка).
Словари и массивы не сравниваются (`maps-not-comparable`).

## Строки

Конкатенация `++` — только для строк. Функции `str(n)` (десятичная запись,
принимает и дробные: `str(20.02) == "20.02"`) и `pad(n, w)` (заполнение нулями
слева до ширины `w`, только целые; ширина больше 1024 — `string-too-long`).

Чтобы проверить строку по нескольким вариантам, перечислите их через
`or` в скобках справа от `==` или `!=`. Например, так можно проверить
дату по списку праздников:

```cyclo
pred holiday(at) = datestr(at) == ("2026-11-04" or "2026-12-31");
```

## Даты

При сравнении `at` со строкой используется местное время расчёта
(`at.wall`). Дату для такого сравнения можно записать в виде
`YYYY-MM-DD`, `YYYY-MM-DDTHH:MM` или `YYYY-MM-DDTHH:MM:SS[.mmm]`.
Пропущенные компоненты считаются нулевыми. Например,
`at >= "2026-01-10"` сравнивает момент строки с полуночью 10 января.
Форматы дат со смещением для аргументов команд и `start_time` описаны
в [справочнике CLI](cli.md#dates-and-durations).

Функция `mkdate(y, mo, d, h, mi, s, ms)` строит словарь
`{wall, abs, zone}` из компонентов местного времени. Для расчёта
`abs` из `wall` вычитается смещение `zone`. Месяц должен быть в
диапазоне `1..12`, день — в пределах месяца, часы — `0..23`, минуты
и секунды — `0..59`, миллисекунды — `0..999`. Неверные компоненты
вызывают ошибку `invalid-date`:

```text
invalid date '2026-13-40T0:0:0.0'
```

## Битовые операции

Операции `<<`, `>>`, `&`, `|`, `^` — только над целыми числами (дробные —
`type-mismatch`), переполниться не могут: биты за пределами 64-разрядного числа отбрасываются.
Сдвиг вправо `>>` — логический (заполнение нулями), величина сдвига берётся
по модулю 64:

```cyclo
[(1 << 70) == 64] 2h: DEPOT.depart();  // 70 → 6, 2^6 = 64 — событие в 2:00
```

## Логические выражения в арифметике

Скобки могут группировать условие. Например, `[(hour(at) >= 0)]` равнозначно
`[hour(at) >= 0]`. Если условие в скобках используется в арифметическом
выражении, оно даёт `1` при истинном результате и `0` при ложном:

```cyclo
[(hour(at) >= 0) == 1] 7h: DEPOT.depart();  // истина → 1 — событие есть
[1 * (hour(at) >= 7) == 1] 7h: DEPOT.depart();  // в 7:00 истина → 1 — событие есть
```

Арифметическое выражение в скобках сохраняет своё числовое значение, например `[(hour(at) + 1) == 8]`.

## Проверка выражений

До расчёта событий движок проверяет типы, число аргументов и рекурсию
объявлений. На этом же этапе обнаруживаются, например, деление на
литеральный ноль, неверная дата в `mkdate` с постоянными аргументами
и числовой литерал за пределами диапазона типа.

Ошибки, зависящие от значений при запуске, обнаруживаются при вычислении
строки. К ним относятся деление на результат, равный нулю, переполнение,
обращение к отсутствующему полю (`unknown-field`) и выход индекса за
пределы массива (`index-out-of-bounds`). Индекс должен быть целым числом.
