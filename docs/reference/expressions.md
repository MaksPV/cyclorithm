# Выражения

Чем считаются условия, блоки и аргументы: значения, арифметика, строки,
даты, битовые операции. Приоритет операций — в [синтаксисе](syntax.md).

## Значения

Пять видов: числа (`i64`; `at` — миллисекунды от epoch), строки,
`true`/`false` (с границей слова: `truex` — имя, не литерал), словари
и массивы. Отдельного типа «булево» нет: условие —
это сравнение, логика `not`/`and`/`or` или вызов предиката, а не значение.

## Арифметика

Операции `+`, `-`, `*`, `/`, `%`, `floordiv`, `floormod`, унарный минус.
Деление `/` усекает к нулю, остаток `%` наследует знак делимого;
`floordiv`/`floormod` округляют к минус бесконечности.

Деление и остаток на ноль — ошибка `division-by-zero`: константный ноль
ловится сразу, ноль выражением — в момент строки.

```text
division by zero
```

Переполнение любой операции — ошибка `integer-out-of-range`, тоже в момент
строки.

## Сравнения

Число сравнивается с числом, строка со строкой (побайтово), все шесть
операторов. Цепочки запрещены (`a < b < c` — синтаксическая ошибка).
Словари и массивы не сравниваются (`maps-not-comparable`).

## Строки

Конкатенация `++` — только для строк. Функции `str(n)` (десятичная запись)
и `pad(n, w)` (добивка нулями слева до ширины `w`).

Список дат — строковой альтернацией, только со строкой слева и только
`==`/`!=`. Ветки — числовые выражения, `and` внутри веток — синтаксическая
ошибка:

```text
pred holiday(at) = datestr(at) == ("2026-11-04" or "2026-12-31");
```

## Даты

Конструктор `mkdate(y, mo, d, h, mi, s, ms)` собирает наивное время:
месяц `1..12`, день в пределах месяца, часы `0..23`, минуты и секунды
`0..59`, миллисекунды `0..999`. Кривые компоненты — ошибка `invalid-date`:

```text
invalid date '2026-13-40T0:0:0.0'
```

Голый `at` рядом со строкой приводится к канонической форме `datetimestr(at)`
(`YYYY-MM-DDTHH:MM:SS.mmm`).

## Битовые

Операции `<<`, `>>`, `&`, `|`, `^` — только над числами, переполниться
не могут: лишние биты роняются (wrap). Сдвиг вправо `>>` — логический
(добивка нулями), величина сдвига берётся по модулю 64:

```text
[(1 << 70) == 64] 2h: DEPOT.depart();  // 70 → 6, 2^6 = 64 — событие в 2:00
```

## Мостик `truth`

Скобки с условием в позиции условия — группировка, а не значение: записать
`[(hour(at) >= 0) == 1]` нельзя, парсер ждёт конец условия после скобки.
Чтобы внести истину в арифметику, условие вкладывается в вычисление —
даёт `1` или `0`:

```text
[1 * (hour(at) >= 7) == 1] 7h: DEPOT.depart();  // в 7:00 истина → 1 — событие есть
```

Скобки с чистой арифметикой — обычный операнд: `[(hour(at) + 1) == 8]`.

## Две проверки

Статика ловит до разворачивания: смешение типов, неверную арность,
константный ноль, кривой константный `mkdate`, невлезающий литерал числа,
рекурсию объявлений. Остальное — в момент строки: ноль выражением, кривой
`mkdate` выражением, переполнение, ошибки доступа к данным (`unknown-field`,
`index-out-of-bounds`).
