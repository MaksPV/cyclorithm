# Ошибки E01–E16

Формат: текст ошибки — в stderr, stdout остаётся пустым. Коды возврата:
`0` — успех, `1` — ошибка ввода, парсинга или валидации,
`2` — некорректные аргументы CLI (текст usage).
Точные формулировки — в [legacy §5](spec-legacy.md); конструкторы —
`Error::eNN_*` в `crates/cyclorithm-core/src/lib.rs`.

Ошибки синтаксиса (файл не разбирается по грамматике, включая отсутствие
корневого цикла) возвращают код `1` без кода `E**`. Импорты (`E13`, `E14`)
разрешаются раньше проверок решётки. Фазы валидации выполняются
в фиксированном порядке, первая ошибка побеждает: имена → рекурсия →
таблицы → длительности и границы → условия → даты. Внутри фазы проверки
идут в порядке объявления.

| Код | Значение | Типичное исправление |
|-----|---------|----------------------|
| E01 | Неизвестная точка (`unknown point`) | Объявить точку `point` или исправить имя |
| E02 | Действие не входит в точку (`action … not allowed`) | Добавить действие в `actions` точки |
| E03 | Неизвестный цикл (`unknown cycle`) | Объявить цикл `cycle`; проверить форму вызова `A()` или `A.b()` |
| E04 | Повторное объявление (`duplicate point/routine/table/slot/param`) | Устранить повтор имени внутри файла |
| E05 | Некорректная длительность (`invalid duration`) | Порядок `w>d>h>m>s>ms`, уникальность компонентов, вместимость в `i64` |
| E06 | Рекурсивный вызов (`recursive cycle/routine/table`) | Разорвать цепочку вызовов |
| E07 | Выход за границу цикла (`overruns`, `out of bounds`) | Увеличить `duration` или сдвинуть строку |
| E08 | Некорректные дата/время (`invalid datetime`) | В файле — строгая форма `YYYY-MM-DDTHH:MM:SS[.mmm]` |
| E09 | Имя неверного рода (`X is not a cycle/point/routine`) | Переименовать: имя занято сущностью другого рода |
| E10 | Некорректный повтор (`invalid repeat`, `fill of zero-duration`, повтор действия) | `N ≥ 1`, ненулевая длительность цикла, повторы только для циклов |
| E11 | Неизвестное имя (`unknown name`) | Проверить параметр, объявление, `at`, системное имя; данные — только через параметр |
| E12 | Некорректное выражение (`type mismatch`, `division by zero`, `invalid date`, …) | Типы операндов, арность, делитель, даты, доступ к данным |
| E13 | Ошибка импорта (`cannot read import`, `import cycle`) | Путь от директории файла; исключить циклические импорты |
| E14 | Расписание в импорте (`schedule not allowed in import`) | Оставить в библиотеке только объявления |
| E15 | Повторный ключ атрибутов (`duplicate attribute`) | Устранить повтор ключа в мапе или атрибутах действия |
| E16 | Неизвестные таблица или метка (`unknown table/slot`, `invalid table argument`) | Передать таблицу литеральным именем; убедиться, что метка существует в таблице |

Негативные примеры: `examples/invalid/bad_*.cyclo` — не менее одного файла
на код ошибки. Правило проекта: новый код ошибки требует пример,
строку в таблице и тест.
