# Стандартная библиотека

Неявно подставляется перед каждой программой; директива `use` не требуется.
Повторное определение системного имени в программе допустимо: побеждает
последнее определение. Имена с префиксом `__` видимы только в собственном
файле; обращение к чужому `__`-имени — ошибка `unknown-name`.

## Календарь

Предикаты `weekend`, `workday`, времена суток `morning`/`afternoon`/`evening`/
`night`, сезоны `spring`–`winter`, компоненты `hour`/`minute`/`day`/`month`/
`year`/`quarter`, дни недели `dow` (0 — понедельник … 6 — воскресенье) и
`day_of_week` (1 — понедельник … 7 — воскресенье, ISO), `datestr`/
`datetimestr`, `start_of_day`/`start_of_month`, `is_leap`/`days_in_month`,
константы `mon`–`sun`, `DAY`.

Списки дат записываются строковой альтернацией:

```text
pred holiday(at) = datestr(at) == ("2026-11-04" or "2026-12-31");
```

## Строки и даты

Функции `str(n)` (десятичная запись числа) и `pad(n, w)` (дополнение нулями
слева до ширины `w`), операции `floordiv`/`floormod`, конструктор даты
`mkdate(y, mo, d, h, mi, s, ms)` (наивное время; некорректные компоненты —
ошибка `invalid-date`).

## Детерминированная случайность

Функция `rand(t)` — xorshift32 от младших 32 бит миллисекунд аргумента,
результат `0..9999`. Чистая функция: одинаковый вход даёт одинаковый выход
в любом прогоне. Пример: `[rand(at) < 5000]` — равновероятный выбор.
