# Стандартная библиотека

Подставляется неявно перед каждой программой; директива `use` не требуется.
Повторное определение системного имени в программе допустимо: побеждает
последнее определение. Служебные имена с префиксом `__` недоступны
из программы.

## Компоненты времени

Все берут момент и возвращают число:

| Имя | Что возвращает |
|-----|---------------|
| `hour(t)` | Час суток, `0..23` |
| `minute(t)` | Минута часа, `0..59` |
| `second(t)` | Секунда минуты, `0..59` |
| `millisecond(t)` | Миллисекунда секунды, `0..999` |
| `day(t)` | День месяца, `1..31` |
| `month(t)` | Месяц, `1..12` |
| `year(t)` | Год |
| `quarter(t)` | Квартал, `1..4` |
| `dow(t)` | День недели, `0` — пн … `6` — вс |
| `day_of_week(t)` | День недели ISO, `1` — пн … `7` — вс |
| `days(t)` | Целые сутки от epoch |
| `day_millis(t)` | Миллисекунды внутри суток |
| `start_of_day(t)` | Полночь тех же суток |
| `start_of_month(t)` | Полночь первого числа месяца |

## Предикаты

Все берут момент `at`:

| Имя | Когда истина |
|-----|-------------|
| `weekend(at)` | Суббота или воскресенье |
| `workday(at)` | Будни (`dow < 5`) |
| `morning(at)` | `6:00`–`12:00` |
| `afternoon(at)` | `12:00`–`18:00` |
| `evening(at)` | `18:00`–`22:00` |
| `night(at)` | `22:00`–`6:00` |
| `spring(at)` | Март–май |
| `summer(at)` | Июнь–август |
| `autumn(at)` | Сентябрь–ноябрь |
| `winter(at)` | Декабрь–февраль |

Списки дат записываются строковой альтернацией:

```text
pred holiday(at) = datestr(at) == ("2026-11-04" or "2026-12-31");
```

## Строки, даты, календарь

| Имя | Что делает |
|-----|-----------|
| `datestr(t)` | Дата `YYYY-MM-DD` |
| `datetimestr(t)` | Момент `YYYY-MM-DDTHH:MM:SS.mmm` |
| `is_leap(t)` | `1`, если год високосный, иначе `0` |
| `days_in_month(t)` | Число дней в месяце |
| `str(n)` | Десятичная запись числа (встроенная) |
| `pad(n, w)` | Запись с добивкой нулями слева до ширины `w` (встроенная) |
| `mkdate(y, mo, d, h, mi, s, ms)` | Момент из компонентов; кривые — ошибка `invalid-date` (встроенная) |

## Константы

| Имя | Значение |
|-----|---------|
| `DAY` | `86400000` (миллисекунд в сутках) |
| `mon` | `0` (понедельник, под `dow`) |
| `tue` | `1` |
| `wed` | `2` |
| `thu` | `3` |
| `fri` | `4` |
| `sat` | `5` |
| `sun` | `6` |

## Детерминированная случайность

Функция `rand(t)` — xorshift32 от младших 32 бит миллисекунд аргумента,
результат `0..9999`. Чистая функция: одинаковый вход даёт одинаковый выход
в любом прогоне. Пример: `[rand(at) < 5000]` — равновероятный выбор.
