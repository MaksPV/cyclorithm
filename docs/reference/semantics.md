# Семантика

Полный перечень из 22 правил — в [legacy §4](spec-legacy.md).
Здесь — опорные правила разворачивания циклов в события.
Термины — по [глоссарию](../glossary.md).

## Решётка корневого цикла

Якорь `T0 = start_time`, период `P = duration`. Старты экземпляров:
`T(k) = T0 + k·P`, `k = 0, 1, 2, …`. Движок строит экземпляры-кандидаты
с `T(k) < end` начиная с минимального `k`, чьи события могут попасть в окно;
в вывод включаются события с временем в `[start, end)`.

## Строки и вложенность

Строка выполняется в момент «старт объемлющего цикла плюс смещение».
Вызов цикла раскрывается рекурсивно с накоплением смещений; вложенность
не ограничена, кроме запрета рекурсии. Вызов действия даёт событие в момент
строки. Пропуск родителя (ложное условие) подавляет потомков.

## Границы (`E07`)

Фактическая длительность цикла — самый поздний конец его строк — обязана
умещаться в объявленную длительность: `actual(C) ≤ duration(C)`.
Завершение ровно в границу допустимо. Цепочки, пересекающие границу периода
корневого цикла, запрещены; для них выбирается больший `duration`
или сдвинутый `start_time`.

## Повторы

- `repeat N` — строгий режим: ровно `N` экземпляров (`N ≥ 1`).
  Выход цепочки за границу объемлющего цикла — ошибка `E07` на строке.
- `fill [until T]` — мягкий режим: экземпляры добавляются, пока
  `старт + duration ≤ горизонт`, где горизонт — конец объемлющего цикла
  для `fill` и смещение `T` от старта объемлющего цикла для `fill until T`.
  Непоместившиеся экземпляры пропускаются без ошибки; ноль поместившихся —
  ноль событий.
- Условие на цепочке проверяется для каждого экземпляра в его старте:
  ложное значение подавляет только этот экземпляр (разрывы, не сдвиг сетки).

## Условия и момент строки

Момент строки `at` — абсолютное время строки. В телах объявлений `fun`/`pred`
`at` означает время места вызова. Статический расчёт фактической длительности
и проверка `E07` выполняются в предположении истинности всех условий.

## Параметры и данные

Аргументы вызова вычисляются в момент строки в окружении вызывающего;
область видимости динамическая — окружение передаётся вниз по цепочке вызовов.
Параметр перекрывает объявление `const`/`fun`/`pred` с тем же именем в теле
цикла. Имя константы-данных непосредственно в условии запрещено (`E11`);
данные доступны условию только через параметр. Табличный параметр рутины
в условиях и блоках невидим (`E11`).

## Таблицы времени и рутины

Вызов `ИМЯ(ТАБЛИЦА, …)` заменяет метки тела смещениями таблицы, добавляет
вызовы таблицы после строк тела; длительность вызова равна длительности
таблицы. Отсутствие метки в таблице — ошибка `E16`. Таблица обязана покрывать
все метки тела рутины; неполное покрытие — ошибка, а не пропуск строк.
