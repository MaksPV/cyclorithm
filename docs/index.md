# Cyclorithm

**Cyclorithm — язык для описания циклических расписаний. Движок проверяет расписание и возвращает список событий за выбранный период.**

```cyclo
cycle CITY_ROUTE duration = 1h20m {
  0m: DEPOT.depart();
  40m: AIRPORT.arrive();
}
```

```console
$ cyclo run route.cyclo --start 2026-01-09T00:00:00 --end 2026-01-10T00:00:00
```

Команда выводит JSON-объект с 18 событиями за 9 января 2026 года.
Чтобы составить и запустить своё первое расписание, воспользуйтесь [пошаговым руководством](getting-started/tutorial.md).

## Сравнение способов записи расписаний

| | Cyclorithm | cron | systemd `OnCalendar` | RRULE |
|---|---|---|---|---|
| Основной элемент | Строка с вызовом и данными | Строка расписания | Календарное выражение | Правило повторения события |
| Связи между запусками | Вложенные циклы и зависимости между запусками | Независимые строки | Независимые выражения | Независимые правила повторения |
| Календарные условия | Предикаты, например `weekend`, и собственные проверки дат | Поля календаря | Поля календарного выражения | Параметры повторения и исключения `EXDATE` |
| Данные событий | `action_attrs`, `point_attrs` | Нет | Нет | Нет |
| Точность | Секунды и миллисекунды | Минуты | Секунды | Секунды |
| Проверка до запуска | Границы, рекурсия, имена | Нет | Только синтаксис (`systemd-analyze calendar`) | Нет |

Запуск в 06:30 по будням в cron задаёт выражение `30 6 * * 1-5`.
В Cyclorithm при суточном корневом цикле со стартом в полночь то же
расписание задаёт строка `[not weekend(at)] 6h30m: CITY_ROUTE();`.
