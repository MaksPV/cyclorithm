## Подсветка кода `.cyclo`

Блоки языка сейчас размечены как plain `text` — монохром. Нужно: собственный
лексер (Pygments для mkdocs-рендера, highlight.js или TextMate-грамматика
для плейграунда и редакторов), затем заменить `text` на `cyclo` по всей вики.
Ключевые слова, строки, комментарии, длительности, имена точек/циклов —
минимум для читаемости.

## Разворот циклов `reverse`

Производный цикл из имеющегося: смещения зеркалятся относительно
длительности (`o' = duration − o`), действия, параметры и условия едут
как есть. Мотив — 101-й: прямое и обратное направления без ручного
дублирования. Проверка границ — на результате, общим порядком
(`cycle-overruns`).

Пример: плечо `0m / 10m / 30m / 50m` при `duration = 1h` даёт
`60m / 50m / 30m / 10m`. Плечи реальных маршрутов
бывают асимметричны (101-й: обратно `TATANOVO` на 20-й, а не 30-й минуте) —
там результат зеркала правится руками. Синтаксис объявления — на отдельное
обдумывание.
