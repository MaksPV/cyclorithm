# Планы

## Экспорт в календарь (ICS)

**Статус** — запланировано.

Добавить флаг `--format ics` в `run` и `next`. Результат в формате
iCalendar (RFC 5545) будет содержать по одному `VEVENT` на событие.
Для мгновенных событий поле `DTEND` не требуется. Сочетание с
`--ndjson` будет возвращать код `2`.

- `UID` вычисляется из расписания, времени, действия, точки и порядкового номера.
- `DTSTAMP` содержит время формирования выгрузки.
- `DTSTART` содержит время в UTC с суффиксом `Z` для окна со смещением
  или местное время без суффикса для окна без смещения.
- `SUMMARY` содержит `action @ point`, а `DESCRIPTION` — JSON-объект `action_attrs`.

Проверять выгрузку по эталону `examples/valid/route.ics`.

## HTTP-сервер

**Статус** — запланировано.

Добавить сервер `cyclorithm-serve` на `tiny_http` с маршрутами `POST /run`,
`POST /next` и `GET /health`. Для запуска подготовить образ Docker
с многоэтапной сборкой.

## Часовые пояса IANA и DST {#iana-and-dst}

**Статус** — запланировано.

Поддержать имена часовых поясов, например `Europe/Moscow`, через
`chrono-tz`. Корневой цикл будет повторяться по местному времени.
При переводе часов вперёд запуск сдвинется вперёд. Если одно и то же местное время встречается дважды, запуск
произойдёт при первом его наступлении. Эти случаи нужно покрыть тестами.

Сейчас `timezone` принимает только `Z` и фиксированные смещения
`±HH:MM`. Сутки всегда длятся 24 часа.
