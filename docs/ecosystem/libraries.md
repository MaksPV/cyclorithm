# Библиотеки и импорт `use`

Общие объявления можно вынести в библиотеку и подключить через `use` до блока `schedule`:

```cyclo
use "libs/route_lib.cyclo";
```

- Путь отсчитывается от каталога файла с директивой `use`. Библиотека может импортировать другие библиотеки.
- Библиотека содержит только объявления (`const`/`fun`/`pred`/`time_const`);
  расписание `schedule` в ней запрещено (`schedule-in-import`).
- Сначала загружается стандартная библиотека, затем зависимости, затем объявления программы.
  Если имя встречается в нескольких файлах, действует последнее объявление. Повторное объявление
  внутри одного файла — ошибка `duplicate`.
- Имена с префиксом `__` границу файла не пересекают (обращение к чужому —
  ошибка `unknown-name`).
- Отсутствующий файл и циклический импорт — ошибки `cannot-read-import` и `import-cycle`.

Контрактный пример: `examples/valid/route.cyclo` + `libs/route_lib.cyclo`.

## Библиотеки для использования в расписаниях (`examples/real/libs/`)

Эти библиотеки можно подключать к своим расписаниям. Например, из файла
в `examples/valid/` путь к юлианскому календарю будет
`../real/libs/julian.cyclo`.

- `julian.cyclo` преобразует местное время в дату по юлианскому календарю
  (`j_year`, `j_month`, `j_day`, `j_datestr`). Функция `julian_to_wall`
  выполняет обратное преобразование, `j_shift` сдвигает дату. День недели
  при переходе между календарями сохраняется (`j_dow = dow`). Неверные
  компоненты даты приводят к ошибке `division-by-zero`.
  Примеры: `examples/valid/julian.cyclo`, `examples/valid/julian_1900.cyclo`.

## Вспомогательные файлы тестов (`examples/valid/libs/`)

Эти файлы используются вместе с примерами сквозных тестов.

- `route_lib.cyclo` — объявления для примера `route.cyclo`.
- `holidays.cyclo` — выходные для теста импортов (`examples/valid/imports.cyclo`).
