# Библиотеки и импорт `use`

Общий код выносится в библиотеки и подключается первой строкой файла:

```text
use "libs/route_lib.cyclo";
```

- Путь — от директории импортирующего файла, импорты транзитивны.
- Библиотека содержит только объявления (`const`/`fun`/`pred`/`time_const`);
  расписание `schedule` в ней запрещено (`schedule-in-import`).
- Порядок наложения: системный файл → импорты вглубь → тело программы.
  Одно имя в разных файлах перекрывается последним; повторное объявление
  внутри одного файла — ошибка `duplicate`.
- Имена с префиксом `__` границу файла не пересекают (обращение к чужому —
  ошибка `unknown-name`).
- Ненайденный файл и циклический импорт — ошибки `cannot-read-import` и `import-cycle`.

Контрактный пример: `examples/valid/route.cyclo` + `libs/route_lib.cyclo`.
