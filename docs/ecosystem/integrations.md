# Интеграции

## WASM-плейграунд

[Плейграунд](https://makspv.github.io/cyclorithm-playground/) ([репозиторий](https://github.com/MaksPV/cyclorithm-playground)): парсер и ядро выполняются
в браузере, фасад — `run_schedule(src, start, end, libs)`, интерфейс —
таймлайн и таблица. Ошибки валидации позиций не несут — визуально
подсвечивается только синтаксис.

## cyclo-agent

[Демон и панель управления](https://github.com/MaksPV/cyclo-agent): исполняет
команды из `.cyclo`-файла (проверки, бэкапы, скрипты), ведёт историю запусков
в SQLite, показывает графики, редактирует расписание через веб-морду. Один
статический бинарь без докера — для серверов, роутеров и одноплатников
(есть сборки под `x86_64`/`aarch64`/`armv7` и Android/Termux, см. релизы).

Связка с языком: исполняется один файл расписания, остальные `.cyclo` рядом —
модули для `use`. Задача — это JSON в строке `fire`, он становится
`action_attrs` события:

```cyclo
0m: JOB.fire() {"cmd": "/bin/echo", "args": ["backup"], "tags": ["backup"], "timeout_s": 1800};
```

Виды задач — циклами-обёртками по видам (`exec`: `cmd`/`args`, `http`:
`check`/`url`/`expect`, `tcp`: `check`/`host`/`port`; общие поля — `tags`,
`timeout_s`). Подробности — в README агента.
