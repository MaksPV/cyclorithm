# Интеграции

## WASM-плейграунд

В [редакторе расписаний](https://makspv.github.io/cyclorithm-playground/)
можно рассчитать расписание прямо в браузере и посмотреть события на
временной шкале или в таблице. Редактор вызывает
`run_schedule(src, start, end, libs)` через WebAssembly. Он подсвечивает
место синтаксической ошибки и показывает сообщения об остальных ошибках
без привязки к строкам. [Репозиторий редактора](https://github.com/MaksPV/cyclorithm-playground).

## cyclo-agent

[cyclo-agent](https://github.com/MaksPV/cyclo-agent) запускает по расписанию
из файла `.cyclo` проверки, резервное копирование и скрипты. Он сохраняет
историю запусков в SQLite. В веб-интерфейсе можно посмотреть графики и
изменить расписание. Агент распространяется как один исполняемый файл
для `x86_64`, `aarch64`, `armv7` и Android/Termux.

Агент запускает одно расписание. Другие файлы `.cyclo` можно подключить
через `use`. Параметры задачи записываются как атрибуты действия `fire`
и попадают в поле `action_attrs`:

```cyclo
0m: JOB.fire() {"cmd": "/bin/echo", "args": ["backup"], "tags": ["backup"], "timeout_s": 1800};
```

У каждого типа задачи свой набор полей:

- `exec` использует `cmd` и `args`.
- `http` использует `check`, `url` и `expect`.
- `tcp` использует `check`, `host` и `port`.

У всех типов есть общие поля `tags` и `timeout_s`. Описания полей приведены
в [документации агента](https://github.com/MaksPV/cyclo-agent).
