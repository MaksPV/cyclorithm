# Глоссарий

Один термин — одно значение. Здесь фиксируем каноничные пары RU/EN;
главы вики обязаны использовать левую колонку.

| Термин | EN | Значение |
|--------|----|---------|
| расписание | schedule | Корневой блок файла, имя — в выводе |
| точка | point | Место, объявляет `actions` и `attrs` |
| действие | action | Именованное событие точки, поле `action` вывода |
| цикл | cycle | Именованная цепочка строк с `duration` |
| корневой цикл | root_cycle | `start_time` + `duration`, решётка экземпляров |
| вызов | invocation | Действие точки / вызов цикла / вызов рутины |
| событие | event | Запись `{time, action, point, point_attrs, action_attrs}` |
| таблица времени | time_const | Именованные слоты, пожары `->` |
| метка (слот) | label / slot | Имя смещения в таблице |
| рутина | routine | Шаблон дня, первый параметр — таблица |
| условие | condition | `[выражение]` перед строкой, считается для `at` |
| момент строки | at | Абсолютное время строки (мс от epoch) |
| повтор | repeat / fill | `repeat N` строго, `fill [until T]` мягко |
| смещение | offset | Смещение строки от старта родителя |
| длительность | duration | Человеческий формат `w/d/h/m/s/ms` |
| фактическая длительность | actual duration | Самый поздний конец строк `max(o + d)` |
| объявление | declaration | `const` / `fun` / `pred` верхнего уровня |
| импорт | use | `use "path";`, путь от директории файла |
| блок действий | action block | `{k = v}` у вызова точки → `action_attrs` |
| атрибуты точки | point attrs | `attrs` точки → `point_attrs` |
| экземпляр | instance | Один запуск цикла в решётке (`k`) |

Запрещённые дубли: «длина» вместо длительности, «слот» вместо метки вне
таблиц, «таска/джоба» вместо события/экземпляра.
