# Глоссарий

| Термин | Значение |
|--------|---------|
| расписание `schedule` | Блок, объединяющий точки, циклы, рутины и корневой цикл |
| точка `point` | Именованный объект с допустимыми действиями `actions` и необязательными атрибутами `attrs` |
| действие `action` | Операция точки, которая при выполнении создаёт событие |
| цикл `cycle` | Именованная последовательность строк с объявленной длительностью `duration` |
| корневой цикл `root_cycle` | Цикл, который запускается автоматически с момента `start_time` и повторяется с периодом `duration` |
| вызов `invocation` | Запуск действия точки, цикла или рутины |
| событие `event` | Запись вывода с полями `time`, `action`, `point`, `point_attrs` и `action_attrs` |
| таблица времени `time_const` | Набор именованных смещений и необязательных вызовов, используемый рутинами |
| метка слота | Имя смещения в таблице времени, например `1st` |
| метка запуска | Имя запуска цикла, объявленное через `as W1`. Начало запуска задаёт `start(W1)`, конец — `end(W1)` |
| курсор | Самое позднее время окончания уже выполненных строк тела текущего цикла. От курсора отсчитываются относительные моменты, например `+10m:` |
| момент строки | Время вызова. Его задаёт смещение, курсор, зависимость от запуска или функция момента |
| рутина `routine` | Шаблон, который получает длительность, смещения меток и вызовы слотов из таблицы времени |
| условие `condition` | Выражение `[…]` перед моментом строки. Оно проверяется для каждого запуска |
| момент строки `at` | Словарь с абсолютным временем (`abs`), смещением от UTC (`zone`) и местным временем (`wall`), всё в миллисекундах |
| контекст экземпляра `here` | Словарь с цепочкой вызовов (`stack`) и записями о строках (`events`, `enabled_events` и `disabled_events`) |
| повтор | Модификатор строки. `repeat N` задаёт число запусков, `fill [until T]` — границу, до которой должны помещаться запуски |
| добивка пустот `fill gaps` | Модификатор строки, который заполняет свободные промежутки окна вызовами цикла |
| смещение `offset` | Расстояние от начала цикла до момента строки. Отрицательное смещение в исходном тексте отсчитывается от конца цикла |
| длительность `duration` | Объявленная продолжительность цикла |
| фактическая длительность | Наибольшее время окончания вызова относительно начала цикла |
| объявление `declaration` | Определение константы `const`, функции `fun`, предиката `pred` или таблицы времени `time_const` |
| импорт `use` | Подключение объявлений из другого файла |
| атрибуты действия | Словарь из вызова действия точки. В выводе хранится в поле `action_attrs` |
| атрибуты точки | Необязательный словарь `attrs`. Копируется в поле `point_attrs` каждого события точки |
