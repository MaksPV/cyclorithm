# Глоссарий

| Термин | Значение |
|--------|---------|
| расписание `schedule` | Корневой блок файла |
| точка `point` | Объект для описания событий; объявляет `actions` и `attrs` |
| действие `action` | Именованное событие точки |
| цикл `cycle` | Именованная цепочка строк `<смещение>: <вызов>;` с длительностью `duration`; сам ничего не порождает, только вызывается |
| корневой цикл `root_cycle` | Входная точка. Работает как цикл, но автоматически вызывается начиная со `start_time`, а когда заканчивается, то вызывается ещё раз |
| вызов `invocation` | Действие точки, вызов цикла или вызов рутины |
| событие `event` | Одна запись вывода `{time, action, point, point_attrs, action_attrs}` |
| таблица времени `time_const` | Список именованных меток времени для рутин |
| метка `label` | Имя смещения в таблице времени |
| рутина `routine` | Шаблон дня; работает как цикл, но наследует длительность, именованные метки и события от таблиц времени. |
| условие `condition` | Выражение `[…]` перед строкой; вычисляется для момента вызова строки |
| момент строки `at` | Абсолютное время строки в миллисекундах от unix epoch |
| повтор | Модификатор строки `repeat N` (ровно `N` запусков) или `fill [until T]` (сколько поместится) |
| смещение `offset` | Смещение строки от старта объемлющего цикла |
| длительность `duration` | Длительность цикла. В коде заранее объявляется сколько длится цикл |
| фактическая длительность | Самый поздний конец строк цикла: `max(смещение + длина вызова)` |
| объявление `declaration` | `const`, `fun` или `pred`  |
| импорт `use` | Подключение стороннего файла в текущий файл. |
| атрибуты действия | `{"k": v, …}` после вызова точки; попадает в событие полем `action_attrs` |
| атрибуты точки | Поле `attrs` точки; копия попадает в каждое событие полем `point_attrs` |
