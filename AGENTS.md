# AGENTS.md — Cyclorithm

## Источник правды
- Канон — `docs/spec.md`. Пример из §1 — исполняемый контракт: `examples/valid/route.cyclo` и `examples/valid/route.expected.json` обязаны совпадать с ним дословно.
- Файлы `описание.md` / `задачи учебные.md` лежат в **родительской** папке (`ScheduleLang/`), это старые размышления, не спека. Не реализовывать по ним.
- Описания вне кода (старые планы в чате) могут противоречить спеке — побеждает спека.

## Рабочий процесс
- Рабочая ветка — `dev` (`main` — стабильная). Коммиты и пуши делает **только владелец** — не коммитить без прямой просьбы.
- Сообщения коммитов — на русском, по содержимому (примеры в `git log`).
- Заглушки — генеральные (`placeholder()`), не проектировать методы/типы вперёд спеки. Проверено на опыте: преждевременные `Event`/`parse()` пришлось откатывать.
- Проверки после правок: `cargo test --workspace` (должен быть зелёным), JSON валидировать парсером, кросс-ссылки кодов ошибок в спеке — через `grep`.

## Архитектура (Cargo workspace, edition 2021)
- `crates/cyclorithm-parser` — грамматика + AST. Решено: парсер на `pest` (EBNF из §3 спеки ложится почти 1:1).
- `crates/cyclorithm-core` — валидация (коды `E01–E09` из §5) + разворачивание решётки + сортировка `(time, k, порядок объявления)`.
- `crates/cyclorithm-cli` — бинарь `cyclo`, контракт CLI в §1 спеки (один JSON в stdout, ошибки в stderr).
- `examples/valid/` — контрактные примеры с `.expected.json` (+ `libs/` — библиотеки для `use`); `examples/invalid/bad_*.cyclo` — по одному минимальному файлу на код ошибки, `bad_syntax.cyclo` — ошибка парсера без кода; `examples/real/` — живые расписания.
- Время внутри — `i64` миллисекунды от unix epoch, наивное (без таймзон); длительности фиксированные (`w=7d`, `d=24h`).

## Ловушки
- Кириллица-латиница: в истории уже создавалась мусорная папка `cyclритм/` из-за одной кириллической буквы в пути. Пути с `cyclorithm` проверять побуквенно; перед созданием файлов — `ls` родителя.
- Рендер GitHub: math-блоки `$$` только с нулевым отступом (внутри списков не рендерятся) и только ASCII внутри (кириллица в `\text{}` ломает KaTeX).
- `ms` в грамматике — единый юнит, в альтернативе `duration_item` обязан идти раньше `m` (иначе лексер разрежет `1ms`).
- Длительность `0` для `root_cycle` запрещена (деление на ноль в решётке) — это кейс `E05`, не забыть при реализации.
- Порядок/уникальность компонентов длительности (`1h2h`, `30s1d`) — уровень валидации, грамматика их пропускает осознанно.
